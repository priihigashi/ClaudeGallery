School rules

Secular only. New schools should normally be GreatSchools 8/10+.
Show score, state grade, grades served, VPK, aftercare, start/end time, admission type, and whether moving nearby helps.
A.D. Henderson = lab lottery; moving nearby does not guarantee admission.
Morikami = magnet/choice; proximity does not guarantee admission.
Hollywood is excluded. Coconut Creek / Wilton Manors are only added if a current 8+/10 school qualifies.

Rental rules

Minimum 2 bed / 2 bath. Prefer houses and townhomes.
Private backyard strongly preferred. A 2/2 without a yard needs a real compensating perk or exceptional proximity/value.
Rent target: normally under $4,000 without pool; up to $4,300 for a strong pool/perk option.
Private pool = solid pink pin. Community pool = pink pin with outer pink ring. Unknown pool = pink dashed ring. No pool = blue.
Research target: up to 10 rental candidates per school, pool-focused.

Property card rules

Show price, beds/baths, sqft, property type, backyard, pool type, perks, school relationship and source-check date.
Add 2–3 preview photos when source URLs are available; full gallery stays linked to Zillow/source.
Research last sold, rent/list history, obvious price increases/drops, repeated turnover, year built and days listed when available.
Property → school drive and current-home → property drive are base estimates; use Google Maps link for live traffic.

Current-home / commute rules

Home base: 1621 NE 34th Ct, Pompano Beach.
Map must show the home pin plus every tracked school area.
For each school: home distance, base drive, school start, and a planning schedule for arriving 60 minutes before school start.
Also show the nearest/on-route VPK and two-dropoff impact when known.

Future purchase reference

Reference only, not an immediate purchase plan.
When inventory exists, target roughly two options around $300K, two around $400–500K, and two around $600–700K per school area.
Up to two remodel candidates; heavy remodel should usually be below ~$400K; around $500K should need lighter work.

Map behavior

Dropdown remains All school areas until the user changes it.
Clicking a school only changes the property focus; it never changes the dropdown.
Default view fits current home + all school areas, including Weston and Delray/Boca.
Desktop list scrolls vertically; mobile property strip scrolls horizontally; popups must remain inside the viewport.
Labels: rent R · $3.5K, sale S · $450K.

Update pipeline

1. Read requirements + pipeline.
2. Research current school/listing sources.
3. Update data and UI.
4. Run syntax/data audit.
5. Push to GitHub and wait for Pages deployment success.
6. Mark completed checklist items and share a cache-busted live URL.
Political context is only added from a verifiable official city/precinct result. Never guess a property's politics from nearby streets.
