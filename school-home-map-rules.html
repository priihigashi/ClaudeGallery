School rules

Secular only. New schools should normally be GreatSchools 8/10+.
Show score, state grade, grades served, VPK, aftercare, start/end time, admission type, and whether moving nearby helps.
A.D. Henderson = lab lottery; moving nearby does not guarantee admission.
Morikami = magnet/choice; proximity does not guarantee admission.
For new schools near the current Pompano home, target 9/10+. Farther alternatives normally require 8/10+. Hollywood is excluded.
Do not add a new school to the live map until it has a usable property set. For Pompano/Oakland Park/Fort Lauderdale, also check objective street/neighborhood context such as walkability, parks, sidewalks and family-use amenities.

Rental rules

Absolute minimum 2 bed / 2 bath; default target is 3 bed / 2 bath+.
Priority: single-family house → strong townhouse → condo/apartment only as a clearly worthwhile fallback.
Private backyard strongly preferred. A 2/2 without yard needs a verified pool, exceptional amenities, unusually strong value/condition, or exceptional school proximity.
A 2/2 under ~1,100 sqft is normally excluded unless it has an unusually strong reason to stay.
Normal budget is around $4,000. Pool / excellent-match homes may stretch to roughly $4,500. ~$5K is reference-only.
Private pool = solid pink. Community pool = pink + solid ring. Pool type not verified = pink + dashed ring. No pool = blue.
Target = 7–10 useful active rentals per school, after eliminating filler.

Property card rules

Show price, beds/baths, sqft, property type, backyard, exact pool type, perks, match quality, target school, and source-check date.
Show property → school base route and current-home → property route when loaded.
Research days listed, last sold, prior rent cycles, price jumps/drops, year built and turnover when the source exposes it.
Show up to 3 embedded preview photos when reusable source-image URLs are available; otherwise show a prominent link to the full listing gallery.

Current-home / commute rules

Home base: 1621 NE 34th Ct, Pompano Beach.
Map must show the home pin plus every tracked school area.
For each school: home distance, base drive, school start, and a planning schedule for arriving 60 minutes before school start.
Also show the nearest/on-route VPK and two-dropoff impact when known.

Future purchase reference

Reference only, not an immediate purchase plan.
When inventory exists, target roughly two options around $300K, two around $400–500K, and two around $600–700K per school area.
Up to two remodel candidates; heavy remodel should usually be below ~$400K; around $500K should need lighter work.

Map behavior

Dropdown remains All school areas until the user explicitly changes it.
Clicking a school centers/focuses the school and properties; it never changes the dropdown.
Default view fits current home + every tracked school area, including Pompano, Boca/Delray, Weston and Cooper City.
Desktop list scrolls vertically; mobile property strip scrolls horizontally; detail cards stay inside the viewport.
Labels: rent R · $3.5K, sale S · $450K. 🏠 marks current home.
Base route times are planning estimates; Google Maps links are provided for live traffic.

Source checks

The direct listing detail page wins over an older search/index result if status conflicts.
Private pool is only marked private when the listing itself supports it. Otherwise use community or unknown.
Inactive/pruned rentals stay in the backup Sheet with the reason.

Update pipeline

1. Read requirements + pipeline.
2. Research current school/listing sources.
3. Update data and UI.
4. Run syntax/data audit.
5. Push to GitHub and wait for Pages deployment success.
6. Mark completed checklist items and share a cache-busted live URL.
Political context is only added from a verifiable official city/precinct result. Never guess a property's politics from nearby streets.
