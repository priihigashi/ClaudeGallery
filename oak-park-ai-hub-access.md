# Oak Park AI Hub Access Request

If you need access to the Oak Park AI Hub, send this message to your admin/IT contact:

> Subject: Access Request — Oak Park AI Hub
>
> Hi [Admin Name],
>
> I need access to the Oak Park AI Hub for [project/team/use case].
>
> My details:
> - Full name: [Your Name]
> - Work email: [your.email@company.com]
> - Department/Team: [Team]
> - Manager: [Manager Name]
> - Access level needed: [Viewer / Editor / Admin]
> - Date needed by: [Date]
>
> Please let me know if you need any additional approvals or forms.
>
> Thank you,
> [Your Name]

## Quick checklist

- Confirm you are using your organization account.
- Include your manager in CC if approval is required.
- Mention exact deadline and reason for access.
- Ask for temporary access if urgent.
